## 📄 Planner가 작성한 분석 계획 전문

### 🎯 OKR — 나의 스터디 일정 최적화

**Objective (목표):**
스터디 시간 배분을 데이터로 분석해, 같은 시간으로 더 많이 배울 수 있는 최적 일정을 찾는다.

**Key Results (핵심 결과 지표):**
1. 과목별 실제 투자 시간 vs 목표 시간 차이를 수치로 파악
2. 집중력이 가장 높은 시간대(요일/시각)를 통계로 확인
3. 3가지 이상의 일정 최적화 방안을 구체적으로 제시

---

### 🗂️ MECE 분석 프레임

> **MECE (Mutually Exclusive Collectively Exhaustive: 상호 배타적이고 전체를 포괄하는 구조)**
> 분석 항목들이 서로 겹치지 않으면서, 중요한 부분이 빠지지 않도록 구성하는 방식입니다.
> 예: "월/수/금" 과 "화/목" 과 "주말" 로 나누면 — 겹치지 않고 ✓, 전체를 포함하고 ✓ → MECE!

#### 분석 항목 (MECE 체크: 겹침 없음 ✓ / 빠짐 없음 ✓)

| 구분 | 분석 내용 | 데이터 필요 |
|------|----------|------------|
| **시간 투자** | 과목별 주당 실투자 시간 | 캘린더 or 직접 입력 |
| **효율성** | 시간 대비 이해도/성취감 | 자기 평가 (1~5점) |
| **패턴** | 집중이 잘 되는 요일/시간대 | 과거 2주 기록 |
| **방해 요소** | 스터디 중단 원인 | 기록 or 추정 |

---

### 📐 분석 방법론

**1단계 — 현황 파악**
- 현재 일정 패턴을 시각화 (차트)
- 목표 vs 실제 시간 갭 계산

**2단계 — 패턴 발견**
- 요일별 / 시간대별 집중도 비교
- 상관관계 분석: 수면 시간 ↔ 다음날 집중력

**3단계 — 최적화 방안**
- 데이터 기반 시간표 재배치 제안
- 단기(1주) / 중기(1달) 실천 계획

### 📚 Sophie에게

안녕하세요, Sophie! Planner입니다. 오늘 우리가 하려는 것을 쉽게 설명할게요.

지금 하려는 분석은 **"지금 어떻게 공부하고 있는지 데이터로 보고, 더 잘 할 수 있는 방법 찾기"** 예요.

마치 운동 선수가 자기 경기 영상을 돌려보고 "아, 여기서 이렇게 하면 더 좋겠다" 하는 것처럼,
우리는 스터디 데이터를 보면서 "화요일 오후가 집중이 잘 되네, 이 시간에 어려운 과목 하자"를 찾는 거예요.

**OKR (Objectives and Key Results: 목표와 측정 가능한 결과)**이라는 방법을 쓰는데,
쉽게 말해서 "무엇을 이루고 싶은가(목표)" + "어떻게 성공했는지 알 수 있나(수치 결과)"를 먼저 정하는 거예요.
목표 없이 분석하면 "그래서 뭐?"가 되거든요. 목표가 있어야 분석이 의미있어져요!

**MECE (Mutually Exclusive Collectively Exhaustive: 중복 없고 빠짐 없는 구조)**는
분석할 때 "빠진 건 없는지, 두 번 세는 건 없는지" 확인하는 체크리스트예요.
예를 들어 과목을 "국어, 영어, 수학, 기타" 로 나누면 — 겹치지 않고, 전부 포함돼요. MECE!

다음 단계에서 Researcher가 이 계획을 받아서 구체적인 분석 방법을 설계할 거예요. 기대해주세요!

💡 오늘의 개념: **OKR** — "무엇을 원하는지(O)"와 "어떻게 이뤘는지 알 수 있는지(KR)"를 먼저 정하면, 분석이 방향을 잃지 않아요.
