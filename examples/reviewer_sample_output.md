### ⚠️ 권고사항 (수정 권고, 필수 아님)

**[권고 1]** 데이터 기간 하드코딩
```python
# 현재 코드
samsung = yf.download('005930.KS', start='2023-01-01', end='2024-12-31')

# 권고 코드 (더 유연함)
from datetime import datetime, timedelta
end_date = datetime.now().strftime('%Y-%m-%d')
start_date = (datetime.now() - timedelta(days=730)).strftime('%Y-%m-%d')
samsung = yf.download('005930.KS', start=start_date, end=end_date)
```

**[권고 2]** 이상치(Outlier) 처리 누락
- 분析 기간 중 급등/급락일이 포함될 경우 상관계수가 왜곡될 수 있음
- 권고: 3 표준편차 밖 데이터 포인트 표시 또는 제외 옵션 추가

**[권고 3]** 롤링 상관계수 미포함
- 정적 상관계수만으로는 "언제 관계가 강해지고 약해지는지" 알 수 없음
- 권고: 90일 롤링 상관계수 추가 차트 → 시간별 패턴 파악 가능

## 📊 통계 검증

### 피어슨 상관계수 가정 확인

| 가정 | 확인 결과 | 판정 |
|------|---------|------|
| 선형 관계 | 산점도에서 선형 패턴 확인됨 | ✅ |
| 정규 분포 | 수익률 데이터는 근사 정규 분포 | ✅ |
| 독립성 | 시계열 데이터 특성상 완전 독립 아님 | ⚠️ 주의 |
| 이상치 없음 | 코로나 급락 등 극단값 포함 가능 | ⚠️ 주의 |

**최종 판정**: 피어슨 상관계수 사용은 적절하나, 시계열 자기상관 (Autocorrelation)을 고려하면 p-value가 약간 과소 추정될 수 있음. 결론의 방향성은 유효.
